# Точка Кода

Сайт проекта индивидуальной разработки на Next.js, TypeScript и App Router.

## Запуск

1. Установите Node.js 20 или новее.
2. Выполните `npm install`.
3. Скопируйте `.env.example` в `.env.local` и заполните значения.
4. Запустите `npm run dev`, затем откройте `http://localhost:3000`.

## Важно перед production

Маршрут `POST /api/requests` сохраняет заявку в PostgreSQL. Выполните SQL из `prisma/migrations/001_requests.sql` в выбранной базе, затем укажите `DATABASE_URL`. Для защиты production добавьте rate limit на уровне reverse proxy или middleware. Telegram-токен должен оставаться только в серверных переменных окружения; уведомление отправляется сервером после успешной записи.

Контакты, текст политики, данные администратора и реквизиты Telegram/VK оставлены настраиваемыми. Не публикуйте сайт до заполнения юридических документов и настройки защищённой авторизации `/admin`.

## Проверка

После установки зависимостей используйте `npm run build`. Рекомендуется проверить страницы на ширинах 375, 768, 1024 и 1440 px, а также сценарии клавиатурной навигации и `prefers-reduced-motion`.
